Project name: FitLog

FitLog is a dark, no-nonsense gym companion app designed to help you track your daily workout plans and stay on top of your fitness goals. It allows users to easily browse, save, and manage exercises in a clean interface.

## Technologies Used
- Next.js
- React
- TypeScript
- Tailwind CSS

## 5 Key Features of the Project
1. **Comprehensive Workout Library:** View detailed breakdowns of various exercises, including barbell bench presses, pull-ups, and squats.
2. **Personalised Plan Management:** Select preferred exercises and add them directly to your "Today's Plan" and "Saved" sections.
3. **Data Persistence:** Uses `localStorage` to ensure all your saved workouts and progress remain intact even after reloading the page.
4. **Interactive UI Actions:** Each workout card includes "Mark as Done" and "Remove" buttons for effortless progress tracking.
5. **Smart Search & Sort:** Filter and sort exercises based on duration, calories burned, and ratings to quickly find the right workout.
